# 知创 · 创作者信号

一个只读的 Chrome / Edge 插件。在 **B站 UP 主个人空间** 中，基于主页简介、已加载作品标题或用户选中的公开文字，生成可解释的「公开商业化信号指数」。无需账号系统、服务器或模型 API Key。

## 安装与使用

1. 下载本项目，或下载 `creator-signal-extension.zip` 后解压。
2. Chrome 打开 `chrome://extensions`（Edge 打开 `edge://extensions`），开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 **extension** 文件夹。
4. 打开一个 B站 UP 主主页，例如 <https://space.bilibili.com/163637592>，等待姓名与简介加载出来。
5. 点击浏览器工具栏中的「知创 · 创作者信号」，检查姓名与 UID，点击「分析这位 UP 主」。
6. 在报告中查看总分、四项得分、命中原文和来源。可点击「大屏查看」或「导出报告 JSON」。

选文分析：先在主页选择 UP 主本人公开发布的文字，再打开插件，选择「选中文字」并确认归属。选文必须至少 8 字。插件不会主动打开登录页面或采集私信。

## 分数如何计算

四项二元规则相加，范围 0–100，每项命中一次即获得该项全部权重，重复出现不叠加：

- 明确商务合作：35 分。例：「商务合作」「合作请联系」。
- 自有商品与付费服务：30 分。例：「淘宝店」「付费课程」「购买链接」。
- 内容赞助声明：25 分。例：「本期由某品牌赞助」「赞助商」。
- 付费支持入口：10 分。例：「给我充电」「打赏支持」。**B站通用充电按钮不计分。**

0 = 本次未观察到；1–34 = 少量公开信号；35–64 = 部分公开信号；65–100 = 多类公开信号。区间和权重是产品规则，不是统计校准结果。代码与具体关键词见 `extension/scoring.js`，版本为 `commercial-v1.0`。

按句匹配并保守排除否定句。例如「不接商单」不会加分；一句中同时出现肯定和否定时也会保守排除该句。规则不能完整理解语义，仍需用户回看原文。分数反映的是**当前样本的信号类别覆盖**，不是收入、合作意愿或接受合作的概率。0 分不表示未商业化。

## 采集范围与边界

- 只支持 `https://space.bilibili.com/数字UID` 的个人空间页面。
- 主页面仅读取指定简介和作品标题节点，不遍历整个正文，不读取评论、推荐、私信或隐藏状态。
- 只分析已经渲染并可见的文字，不自动翻页、不请求站点内部 API，不分析视频画面或语音。
- 选文模式排除可识别的评论/回复区域，但用户仍需确认文字归属；站点结构变化可能影响识别。
- 无可用样本时提示重试或选择公开文字，不生成看似有效的 0 分报告。
- 姓名和 UID 在分析前后校验；报告绑定该次作者、来源、采集时间、模式与规则版本。
- 页面需要登录、验证或网络异常时，由用户在站点处理；插件不绕过访问限制。
- 首版不支持视频播放页、小红书、抖音，也不评价未采集内容。

## 隐私与权限

扩展权限只有 `activeTab`、`scripting`、`storage`。点击插件后临时读取当前页，没有持续的网站访问权限，不读取 Cookie、浏览历史或其他标签页内容。全部分析在本地完成，没有分析服务器或任何上传请求。

本地仅保留最近 10 份报告，包括命中引用、公开来源和创作者身份。未命中的完整采集文字不持久保存。可在「最近的本地报告」中清空。JSON 导出由用户主动触发。原文链接和创作者主页链接由用户点击时在新标签页打开。

## 本地开发与验证

运行时不需要构建；直接加载 `extension/` 即可。测试需要 Node.js 22+：

```sh
npm ci
npx playwright install chromium
npm test
npm run test:e2e
npm run test:live
npm run package
```

- `npm test`：9 个评分测试，覆盖权重、否定、重复、空样本、选文隔离等。
- `npm run test:e2e`：6 个真实扩展浏览器测试，使用明确标注的合成 B站结构页面，覆盖临时权限、主流程、选文确认、导出、历史清空和错误处理。没有伪造浏览器扩展 API。
- `npm run test:live`：打开可见测试浏览器，访问真实 UP 主页面，触发浏览器扩展按钮并点击分析，再打开完整报告；输出截图和实际报告至 `docs/acceptance/`。需要联网，B站页面变动可能改变结果或使其失败。
- `npm run package`：生成可解压加载的 `creator-signal-extension.zip`，不包含开发依赖。

验收步骤和讲解见 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。
