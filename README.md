# 知创 · 创作者信号 v0.2

Chrome / Edge 只读插件。在 **B站 UP 主个人空间** 中，基于主页简介、已加载作品标题或用户确认的公开选文，展示 **品牌合作公开证据等级 E0–E3**、独立的合作状态、变现渠道和原文依据。无需服务器或模型 API Key。

## 安装与使用

1. 下载代码或 `creator-signal-extension.zip` 并解压。
2. Chrome 打开 `chrome://extensions`（Edge：`edge://extensions`），开启「开发者模式」。
3. 点击「加载未打包的扩展程序」，选择包含 `manifest.json` 的 **extension** 文件夹。
4. 打开 <https://space.bilibili.com/163637592> 等 UP 主个人空间，等待姓名、简介和作品加载。
5. 点击工具栏插件，核对姓名及 UID，再点击「分析这位 UP 主」。
6. 查看 E 等级、独立合作状态、引用及来源；可展开等级规则、完整报告、导出 JSON。

选文：先选择主页中由该 UP 主公开发布的文字，再打开插件选「选中文字」，确认文字归属后分析。至少 8 字；选文结果只描述本段，不能推断整个账号。可定位到作品标题的选文保留其作品链接。

已安装旧版时，在扩展管理中点击插件的「重新加载」，然后关闭旧弹窗、重新打开即可。0.1 报告保留并标记旧规则已停用，不会直接换算成 E 等级；请重新分析。

## 界面与操作

- 首屏展示已识别的作者和可用文字范围，选择主页或选文后开始分析。
- 选文少于 8 字或未确认归属时，开始按钮禁用，并提供下一步提示。
- 结果优先展示作者、E 等级、合作状态和可核对的原文；不把全部规则堆在首屏。
- 顶部操作栏随滚动保留，可直接打开完整报告、导出或返回重新分析。
- 点击「项目规则」会展开对应说明并移至该位置；采样范围、边界与披露率说明按需展开。
- 无法识别页面时提供重新识别和 B站入口；历史报告保留作者、模式、时间和等级。
- 清空记录前可取消；导出后提供下载反馈。支持键盘焦点和减少动画偏好。

## 指标定义：证据类别，不是商业化总分

四档是本项目自定义的、可核对的证据规则，不是 B站官方评分、收入估计、合作概率或投放价值。

- **E0：本次未发现合格证据。** 有效样本中未发现下面的正向证据，不代表没有商业合作。
- **E1：发现合作联系线索。** 例如「合作请联系」，尚未明确商业性质；普通邮箱不算。
- **E2：发现明确商务合作声明。** 例如「商务合作请联系」「欢迎品牌合作」。有明确合作自述但缺少具体作品链接时，也至多 E2；自述不等于已核验成交。
- **E3：发现具体作品的合作披露。** 例如某条可定位作品写「本期由品牌 A 赞助」，有具体对象与作品链接。只证明公开披露，未核验合同、交易或收入。

**计算方式：取本次有效证据支持的最高等级。** 不加权、不累加、不换算成百分制。不使用粉丝数、播放量或渠道数量抬高等级。

无法识别作者、未读取到任何有效文字时，显示「无法判断」或错误提示，不生成 E0 报告。

### 合作状态独立判断

只从主页简介或本段无作品关联的选文判断公开状态，不把作品标题或历史赞助直接当成当前意愿：

- 有明确商务合作声明；
- 有联系线索，商务性质未明；
- 明确拒绝或暂停；
- 本次未发现合作声明；
- 公开表述冲突，需核对。

例：某作品披露过赞助，但主页写「暂不接商单」时，可以同时显示 **E3** 与 **明确拒绝或暂停**。它们衡量不同问题。主页声明也仅代表采集时页面保留的文字，不保证真实接单情况或发布时间。

### 变现渠道与未采集数据

商品店铺、付费内容服务、充电/创作支持按证据单列，不提高品牌合作等级。平台通用「充电」按钮、普通产品名不算作者主动声明。

**商业合作披露率暂不计算。** 现有采集仅覆盖简介、标题或单段选文，没有完整视频简介及相关声明，不能构造可信分母。文字段数不等于完整视频数。电磁力、花火后台分数和第三方指数均未获取，不估算。

## 采集范围与限制

- 只支持 `https://space.bilibili.com/数字UID` 的个人空间；不支持视频播放页和其他平台。
- 只读取指定的已渲染简介及作品标题节点，不扫描整个正文，不读取评论、推荐、私信、Cookie 或隐藏状态。
- 最多 50 个文字块；不自动翻页或请求站点内部 API。按文字类型、来源链接与内容去重；作品数按视频 ID 去重。
- 选文排除可识别的评论/回复区域，仍需用户确认作者归属；网页结构变化可能影响识别。
- 同一句中否定、疑问、教程、假设、转述及风险提示保守排除。复杂跨句语义、反讽、指代、品牌实体归属仍可能误判，请核对原文。
- 历史表述单独标注；没有获取发布日期时明确显示未知，不把采集时间伪装成发布时间。
- 页面需要登录、验证或网络异常时，由用户正常处理；插件不绕过访问限制。

## 隐私与权限

只有 `activeTab`、`scripting`、`storage`，与 0.1 相同。点击插件后临时读取当前页，没有持久的网站访问授权，不上传分析内容。外链仅在用户点击后打开。

本地保留最近 10 份报告，包括作者身份、证据引用、来源、采集时间和规则版本。未命中的完整文字不持久保存。可清空或主动导出 JSON。

## 开发与验证

扩展直接加载，无需构建。Node.js 22+：

```sh
npm ci
npx playwright install chromium
npm test
npm run test:e2e
npm run test:live
npm run package
```

- `npm test`：评分规则回归样本，覆盖 E0–E3、普通邮箱、渠道隔离、否定、历史、疑问、冲突、去重、选文归属和空样本。
- `npm run test:e2e`：真实浏览器扩展 API 下的合成页面测试，覆盖分析、选文确认、导出、大屏、清空、旧版兼容和错误处理。
- `npm run test:live`：访问真实 B站主页，触发插件、点击分析并完整报告，输出实际报告及截图至 `docs/acceptance/`。需要联网，未来页面变化会改变结果或导致失败。
- `npm run package`：生成扩展、使用说明与验收材料 的 `creator-signal-extension.zip`。

测试通过只说明程序满足已编写的规则和场景，**不代表获得独立数据集上的准确率、统计校准或官方认证**。
