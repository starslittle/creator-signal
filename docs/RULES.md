# 品牌合作公开证据规则 evidence-v2.0

## 目标与范围

面试验收目标：从 B站创作者主页发起一次公开内容分析，展示一个定义明确的信号指标、计算方式和来源，且结果绑定本次作者。

主指标只回答「本次样本中，最高观察到哪类品牌合作公开证据」，不衡量合作频率、收入、实际成交、广告真实比例、当前真实意愿或品牌投放效果。

E0–E3 为有序类别，没有等距含义：E2 不代表 E1 的两倍，也不应换算为 67/100。

## 判定流程

1. 校验平台、UID、姓名和非空文字。采集失败不给 E0；选文少于 8 字不给结果。
2. 依据类型、URL、文字去重；保留作品归属。选文不混入主页其他内容。
3. 按句和分句解析，识别否定、疑问、教程、假设、转述和风险提示，保守排除并显示理由。
4. 普通邮箱、粉丝数、播放量、评测产品名、平台通用按钮不作品牌合作证据。
5. 「合作请联系」等泛合作入口为 E1。
6. 具有联系或接受等声明语境的商务/品牌/推广合作为 E2；仅出现「商业合作很重要」不算。
7. 明确的作品合作披露，需有具体合作对象和符合 B站视频 URL 格式的链接，才为 E3。简介里没有可定位作品的赞助自述至多 E2。
8. 取所有合格正向证据的最大等级。无合格证据且有有效样本才为 E0。
9. 独立判断主页合作状态、历史表述和变现渠道；它们不互相加减或覆盖。

## 证据要求

每条证据包含：作者 UID、原文引用、命中表述、理由、来源类型、来源 URL、可获取时的作品 ID、采集时间、发布日期（未知为 null）和历史标记。报告包含采样范围、规则及数据结构版本。

作品链接只证明可定位，不证明合同或交易真实。程序没有进入作品页面核验完整正文或调用私有商单数据。当前主页上的作品标题归属依赖页面对应的 UP 主区域；选文归属额外由用户确认，不能视为对作者身份的外部鉴证。

## 当前合作状态

只取主页简介和无作品关联的选文。标题、具体赞助披露和明确含历史词的片段不直接确立当前接单状态。出现相反的当前声明时显示冲突。

「明确拒绝或暂停」可以与 E3 并存。历史有合作不等于今天接单；当前保留联系声明也不保证实际可接单。

## 变现渠道

主动说明的自营店铺/商品入口、付费内容服务、充电/会员支持独立展示。没有品牌合作证据时，即使渠道很多也可为 E0。这不等于这个作者未商业化，而是主指标只测品牌合作证据。

## 披露率后续条件

当前 `disclosureRate.value` 恒为 null，因为 `sample.completeWorks` 为 0。不从标题数、关键词数或选文构造百分比。

未来完整采样后可定义「明确披露品牌合作的视频数 / 成功完整读取所需公开字段的样本数」，同时展示抽样窗口、计划样本、成功和失败样本、缺失原因，不能把未读取或未检出当成非商单。该统计口径仍应注明为本项目定义，不是官方公式。

## 验证与局限

测试中的预期分类是人工编写的规则回归用例；合成页面测试验证端到端流程；真实 UP 主测试验证公开页面可用性。三者不能代替独立标注集，不能据此声称高准确率或给出概率置信度。

当前实现为保守文本规则，不具备完整的语义理解或品牌实体识别。跨句否定、反讽、引述边界、未写明的历史语境、个人赞助与品牌赞助区分等仍可能误判。证据分级需供人工核对，不能作为对作者的商业事实鉴定。

- [OECD合成指标方法手册](https://www.oecd.org/en/publications/handbook-on-constructing-composite-indicators-methodology-and-user-guide_9789264043466-en.html)强调测量目的、数据和组合方法；它不提供本项目的创作者评分标准。
