## 现场演示，约两分钟

1. 按 README 加载 `extension/`，打开上面的 B站主页，等待简介和作品标题加载。
2. 打开插件，指出姓名与 UID，与网页一致。
3. 选择「主页公开内容」，点击分析。
4. 解释 35 分来自哪里：四类权重相加，主页简介中的明确合作入口命中 35 分；同类不重复计分，其他项没有本次可见证据所以为 0。
5. 点击来源打开原主页，核对引用。展开「计算方式与分数含义」。
6. 点击「大屏查看」展示完整报告，或导出 JSON。
7. 可再选中简介中的公开文字，用「选中文字」演示第二种入口，先确认文字归属。

如果页面登录/验证/加载失败，先在网页正常处理。也可选择主页中已展示的 UP 主公开文字分析。插件不绕过站点限制，也不把空样本当成 0 分。

## 面试讲解要点

产品范围：只做 B站个人空间，先把一个平台的一次分析做完整。没有堆叠跨平台爬虫和外部模型依赖。

方法：本地透明规则。四类权重为 35、30、25、10，合计 100；按句匹配，命中一项计一次；否定句保守排除。权重为 MVP 的产品设计，没有声称经过真实商业收益标定。

可信性：报告绑定姓名、UID、原始主页、采集时间、分析模式和规则版本；每条正向证据保留引用和链接；报告展示样本数量、字符数和边界。

隐私：点击插件才临时读取网页；不抓取评论、私信、隐藏页面数据或 Cookie；不上传；保留最近 10 份本地报告，可清空。

限制：标题与简介只能证明观察到的文字信号，无法证明实际收入、真实合作关系或私下意愿。关键词可误判；商品评测不自动当成广告。未加载、未展开、视频内容均未参与。

## 验证覆盖

9 个评分测试：总权重与封顶、否定、真实合作表述、非信号词、空样本、选文隔离、缺失身份、去重与来源、跨句否定。

6 个浏览器扩展测试：完整流程与导出清空、选文确认与独立计分、空样本提示、不支持的网站、未加载身份、评论选文排除。此部分使用合成页面保证可重复；与上方真实线上验收明确区分。
